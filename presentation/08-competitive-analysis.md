# ACTIRA — Competitive Analysis

---

## Category

**AI-assisted IR / SOC copilot** (not primary detection platform)

---

## Landscape

| Product                    | Strength            | ACTIRA angle                              |
|----------------------------|---------------------|-------------------------------------------|
| ChatGPT / generic LLM      | Flexible            | No grounding/HiTL/audit productization    |
| Microsoft Security Copilot | Deep M365/Defender  | Closed, cost, ecosystem lock-in           |
| Cortex XSOAR               | Orchestration depth | Heavy; ACTIRA is advisory-first OSS       |
| Splunk ES / Sentinel       | Detection + UEBA    | ACTIRA complements with playbook drafts   |
| Elastic Security           | Search scale        | ACTIRA focuses IR narrative + HiTL        |
| Open SOAR (TheHive, etc.)  | Case mgmt           | ACTIRA stronger on grounded LLM playbooks |

---

## Positioning matrix

```
High automation →  SOAR suites
                   ↑
Grounded AI IR  →  ACTIRA (here)
                   ↓
Chat paste      →  Generic LLM
```

## Lose themes (honest)
