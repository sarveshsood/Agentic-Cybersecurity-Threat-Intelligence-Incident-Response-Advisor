## Getting help

| Need                   | Where                                                                                              |
|------------------------|----------------------------------------------------------------------------------------------------|
| Install / run          | [docs/INSTALLATION.md](docs/INSTALLATION.md), [docs/QUICKSTART.md](docs/QUICKSTART.md)             |
| Break / errors         | [TROUBLESHOOTING.md](TROUBLESHOOTING.md), [docs/OPERATIONS_RUNBOOK.md](docs/OPERATIONS_RUNBOOK.md) |
| Architecture           | [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), [diagrams/](diagrams/)                               |

| Feature idea           | GitHub Discussions or Feature issue template                                                       |

## Response expectations (community)

- Best-effort community support on GitHub Issues
- No guaranteed SLA for free/open use
- Security reports: aim to acknowledge within 5 business days (see SECURITY.md)

## Commercial / enterprise support

If you deploy ACTIRA for a production pilot, engage your internal platform team using:

- [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)
