# SOC 2 Alignment (not a certification)

| TSC theme            | Evidence you can show auditors       |
|----------------------|--------------------------------------|
| Security             | RBAC, vault, hardening, CI scans     |
| Availability         | health checks, backups, DR docs      |
| Processing integrity | audit log, golden tests, review 409  |
| Confidentiality      | secret redaction, encryption at rest |
| Privacy              | retention, privacy doc               |

Certification requires organizational controls, pen tests, and evidence collection beyond this repo.
