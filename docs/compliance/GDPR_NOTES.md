# GDPR Notes

If personal data may appear in uploaded logs:

1. Establish lawful basis and DPIA for your deployment
2. Configure retention (`INCIDENT_RETENTION_DAYS`)
3. Restrict access via RBAC
4. Execute DSAR processes operationally (export/delete incidents)
5. Review LLM subprocessors

ACTIRA does not ship a full privacy program UI in v1.0.
