# MITRE D3FEND (illustrative)

| D3FEND idea                          | ACTIRA feature                     |
|--------------------------------------|------------------------------------|
| Credential hardening                 | password policy, JWT hygiene       |
| Isolation (advisory)                 | containment steps in playbooks     |
| Network traffic filtering (advisory) | playbook guidance, not enforcement |
| Process eviction (advisory)          | malware playbook text              |
| Model hardening                      | citation filter, HiTL              |

ACTIRA primarily **recommends** D3FEND-like actions; it does not execute them in v1.0.
