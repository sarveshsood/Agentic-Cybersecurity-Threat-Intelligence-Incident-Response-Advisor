# Appendix F — Glossary

**Location:** `docs/capstone/appendices/F_glossary.md`

| Term | Definition |
|------|------------|
| **ACTIRA** | Agentic Cybersecurity Threat Intelligence & Incident Response Advisor |
| **Alignment score** | Compliance **readiness** metric; not formal certification (ISO/SOC2) |
| **ATT&CK** | MITRE Adversarial Tactics, Techniques, and Common Knowledge |
| **BM25** | Lexical ranking function used in hybrid RAG |
| **CES** | Common Event Schema — normalized event records after parse |
| **Grounding** | Score (0–1) of playbook support from retrieved citations |
| **HiTL** | Human-in-the-Loop — mandatory review gate for high-risk cases |
| **IoC** | Indicator of Compromise (IP, domain, URL, hash, …) |
| **LanceDB** | Vector store used for hybrid retrieval (design choice vs Chroma) |
| **Modular monolith** | Single deployable backend with clear module boundaries |
| **Mock TI** | Deterministic enrichment when TI API keys are absent |
| **NIST SP 800-61** | Computer security incident handling guide (phase structure) |
| **Playbook** | Structured IR response steps with phases and citations |
| **RAG** | Retrieval-Augmented Generation |
| **RCA** | Root cause analysis narrative |
| **RRF** | Reciprocal Rank Fusion — combines BM25 and dense rankings |
| **SOAR** | Security Orchestration, Automation and Response (execution not unsupervised in ACTIRA) |
| **SOC** | Security Operations Center |
| **Template playbook** | Offline / no-LLM fallback IR structure used by golden CI |
| **TI** | Threat intelligence |
| **Vault** | Encrypted storage for API keys in Settings |
| **Wave C** | Product wave adding compliance score, audit intelligence, executive export |
