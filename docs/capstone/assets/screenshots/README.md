## How to capture live UI

1. Start stack (Compose or local API + `npm start`).
2. Walk `docs/DEMO_SCRIPT.md`.
3. Capture each screen at 1280×720+ and **overwrite** the same filenames.
4. Prefer: Login (probed status), Dashboard (no DEMO banner), Workspace, Playbook+citations, Review, Compliance (disclaimer banner visible), Settings LLM.

Product checklist also: `samples/demo/SCREENSHOT_CHECKLIST.md`.
