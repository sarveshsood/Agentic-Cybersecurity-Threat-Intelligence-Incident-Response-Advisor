# ROI Analysis (illustrative)

Assumptions for a 10-analyst SOC pilot:

| Item                                      | Estimate                |
|-------------------------------------------|-------------------------|
| Minutes saved per incident playbook draft | 15–40                   |
| Incidents / week with AI draft            | 20                      |
| Analyst fully loaded cost                 | org-specific            |
| ACTIRA infra cost                         | low (compose/k8s small) |
| LLM cost                                  | dominant variable       |

**Break-even:** often weeks if playbook drafting is frequent — validate with your volumes.

Soft ROI: training consistency, audit readiness, reduced chatbot shadow IT.
