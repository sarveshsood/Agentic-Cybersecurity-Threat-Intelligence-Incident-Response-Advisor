# Pull Request Guidelines

- One problem per PR when possible
- Fill the PR template completely
- Include test evidence
- Update docs/diagrams/OpenAPI when behavior changes
- Security-sensitive PRs need CODEOWNER review
- Keep diffs reviewable (< ~400 lines ideal; split otherwise)

## Definition of done

- [ ] CI green
- [ ] No new critical Bandit findings
- [ ] Docs synced
- [ ] Demo path not broken
- [ ] **Tooltips / HelpTips** on any new UI surface (page, panel, KPI, primary actions) —
      see [TOOLTIP_PREREQUISITE.md](TOOLTIP_PREREQUISITE.md)
