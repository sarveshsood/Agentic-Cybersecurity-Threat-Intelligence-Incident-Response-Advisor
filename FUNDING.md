# Funding

ACTIRA is MIT-licensed open software.

If you maintain a public fork, configure GitHub Sponsors or other funding links here:

```yaml
# .github/FUNDING.yml example
# github: [your-org]
# open_collective: # replace
# custom: ["https://example.com/sponsor"]
```

This file documents intent; enable [GitHub Sponsors](https://github.com/sponsors) when the project is published under a
real org.
